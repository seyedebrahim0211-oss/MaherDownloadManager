ماهر دانلود منیجر

آموزش قدم‌به‌قدم و کاملاً فارسی برای نصب برنامه، ساخت فایل EXE در گیت‌هاب، فعال کردن افزونه مرورگر و دریافت به‌روزرسانی.

ویندوز ۱۰ و ۱۱نسخه ۲.۰بدون نیاز به دانش برنامه‌نویسی برای نصب نسخه آماده
قبل از شروع: فایل MaherDownloader-v2.0-GitHub-Source.zip شامل «کد برنامه و ابزار ساخت» است، نه یک نصب‌کننده آماده. برای نصب ساده، ابتدا باید فایل MaherDownloader-Setup.exe از قسمت Releases مخزن منتشر شده باشد. اگر هنوز وجود ندارد، روش دوم را انجام دهید.
انتخاب راهنما:
۱. نصب ساده با EXE۲. ساخت EXE با GitHub۳. افزونه مرورگر۴. به‌روزرسانی۵. رفع مشکل

روش اول: نصب ساده برنامه روی ویندوز

۱
مخزن برنامه را باز کنید.

به مخزن پروژه خود در سایت github.com بروید و در ستون سمت راست (یا بخش بالای مخزن) گزینه Releases را باز کنید.

۲
نصب‌کننده را دریافت کنید.

در آخرین نسخه منتشرشده، بخش Assets را باز کنید و MaherDownloader-Setup.exe را دانلود کنید. فایل ZIP کد منبع برای نصب مستقیم مناسب نیست.

۳
برنامه را نصب کنید.

فایل EXE را با دو بار کلیک اجرا کنید، مراحل Setup را تا پایان انجام دهید و ماهر دانلود منیجر را از منوی Start باز کنید. برای نسخه EXE نیازی به نصب جداگانه Python ندارید.

اگر در Releases فایل EXE نمی‌بینید، ابتدا روش دوم را انجام دهید تا GitHub برای شما آن را بسازد.

روش دوم: ساخت فایل نصب EXE از طریق GitHub

این روش برای صاحب پروژه است. ساخت نصب‌کننده روی کامپیوتر ویندوزی GitHub انجام می‌شود و نیازی به نصب Python روی رایانه شما ندارد.

۱
یک مخزن ایجاد کنید.

در GitHub روی New repository بزنید؛ نامی مثل MaherDownloadManager انتخاب کنید و مخزن را بسازید.

۲
فایل ZIP را استخراج کنید.

روی فایل ZIP راست‌کلیک کنید و Extract All را بزنید. سپس محتویات داخل پوشه پروژه را انتخاب کنید؛ خود ZIP را در مخزن قرار ندهید.

۳
تمام فایل‌ها را در ریشه مخزن آپلود کنید.

در مخزن Add file → Upload files را بزنید، تمام پوشه‌ها و فایل‌ها را اضافه کنید و Commit changes را انتخاب کنید. مطمئن شوید پوشه .github/workflows/ نیز منتقل شده باشد.

۴
ساخت خودکار را اجرا کنید.

به Actions → Windows installer and GitHub Releases بروید و روی Run workflow کلیک کنید. شاخه پیش‌فرض main یا master را انتخاب کنید و دوباره Run workflow بزنید.

۵
فایل نصب را دریافت کنید.

اجرای تازه را باز کنید. پس از سبز شدن وضعیت، در پایین صفحه زیر Artifacts مورد MaherDownloader-Windows-Installer را دانلود کنید. ZIP خروجی را استخراج کنید؛ فایل MaherDownloader-Setup.exe داخل آن است.

۶
انتشار رسمی نسخه برای دریافت به‌روزرسانی.

برای منتشر کردن در Releases، تگ نسخه مانند v2.0.0 ایجاد کنید. ساده‌ترین روش در وب: Releases → Draft a new release → Choose a tag → Create new tag؛ سپس Publish release. گردش‌کار GitHub با تگ اجرا می‌شود و فایل نصب را به نسخه منتشرشده اضافه می‌کند.

توجه: جریان ساخت نسخه اصلاحی، فایل نصب را به Release موجود نیز اضافه می‌کند؛ بنابراین انتشار از رابط وب GitHub پشتیبانی می‌شود.

روش سوم: فعال‌سازی افزونه دانلود مرورگر

Google Chrome

در نوار آدرس chrome://extensions را وارد کنید. Developer mode را روشن کنید و Load unpacked را بزنید. پوشه browser-extension را انتخاب کنید.

Microsoft Edge

آدرس edge://extensions را باز کنید. Developer mode را روشن کنید و از Load unpacked پوشه browser-extension را اضافه کنید.

اتصال به برنامه: ماهر دانلود منیجر را اجرا کنید، دکمه «کپی کد اتصال مرورگر» را بزنید، روی آیکون افزونه کلیک کنید، کد را جای‌گذاری و ذخیره کنید. سپس در صورت تمایل «انتقال خودکار دانلودهای جدید مرورگر» را فعال کنید.

افزونه Firefox فعلاً آزمایشی و موقت است: about:debugging → This Firefox → Load Temporary Add-on و انتخاب فایل browser-extension-firefox/manifest.json.

به‌روزرسانی برنامه چگونه کار می‌کند؟

برنامه نصب‌شده هنگام شروع، در صورت دسترسی به اینترنت نسخه‌های جدید را از GitHub Releases بررسی می‌کند. با انتشار نسخه جدید و فایل نصب دارای هش SHA-256، برنامه به کاربر اطلاع می‌دهد و بعد از تأیید او نصب‌کننده را اجرا می‌کند. نصب بدون تأیید کاربر انجام نمی‌شود.

نکته مهم برای سازنده: برای فعال بودن آپدیت در نسخه منتشرشده، فایل EXE باید توسط GitHub Actions همان مخزن ساخته شده باشد تا نشانی مخزن در برنامه ثبت شود. صرفاً کپی کردن سورس، به‌روزرسانی را فعال نمی‌کند.

عیب‌یابی خطاهای رایج

گزینه Run workflow وجود ندارد

بررسی کنید فایل .github/workflows/windows-release.yml در شاخه پیش‌فرض قرار گرفته و Actions مخزن فعال باشد. یک بار صفحه را تازه‌سازی کنید.

ساخت ویندوز با رنگ قرمز متوقف شد

روی اجرای ناموفق در Actions کلیک کنید، مرحله خطادار را باز کنید و متن خطای همان مرحله را بررسی کنید. ساخت EXE تا زمانی که اجرا سبز نشود، تأییدشده نیست.

فایل EXE را پیدا نمی‌کنم

پس از اجرای موفق، Artifacts را دانلود و ZIP مربوط به آن را استخراج کنید. برای نصب کاربران عادی، نسخه رسمی را از Releases → Assets دانلود کنید.

افزونه نوشته «برنامه متصل نیست»

خود برنامه باید باز باشد؛ کد اتصال باید از همان نصب فعلی کپی شده باشد. در صورت تغییر برنامه، کد را دوباره در افزونه ذخیره کنید.

متن‌های فارسی نامرتب نمایش داده می‌شوند

این فایل HTML دارای UTF-8 و dir=rtl است؛ آن را مستقیماً در Edge یا Chrome باز کنید. برای مشاهده بدون مرورگر از PDF همراه بسته استفاده کنید.

محدودیت ویدیو و DRM

پشتیبانی از ویدیوهای عمومیِ مجاز و HLS بدون DRM وابسته به شرایط منبع است. این برنامه محافظت DRM را دور نمی‌زند و دانلود همه محتواها یا تمام دریافت‌های داخلی مرورگر را تضمین نمی‌کند.
