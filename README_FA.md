# ماهر دانلود منیجر — نسخه ۲.۰

> **آموزش نصب فارسی اصلاح‌شده:** فایل `INSTALL_FA.html` را با دوبار کلیک در Chrome/Edge باز کنید؛ یا فایل `INSTALL_FA.pdf` را مطالعه کنید. در ویندوز همچنین می‌توانید `OPEN-FA-GUIDE.bat` را اجرا کنید. این سه فایل بدون نصب Python قابل مشاهده‌اند و صفحه HTML به صورت راست‌به‌چپ و UTF-8 طراحی شده است.

**مسیر سریع:** اگر فایل نصب آماده `MaherDownloader-Setup.exe` در بخش **Releases** مخزن موجود است، همان را دریافت و اجرا کنید. اگر وجود ندارد، مطابق روش دوم فایل `INSTALL_FA.html` سورس را داخل مخزن GitHub بارگذاری و از **Actions** خروجی EXE بگیرید.

مدیر دانلود بومی برای Windows 10/11 با رابط فارسی، چهار پوسته الهام‌گرفته از هنر ایرانی، دریافت چندبخشی و افزودنی مرورگر. این پروژه مستقل است؛ به **Internet Download Manager** وابسته نیست.

## امکانات

- دانلود HTTP/HTTPS و FTP؛ دانلود موازی ۱ تا ۱۶ بخش در صورت پشتیبانی واقعی سرور از Range
- ادامه دانلود HTTP با اعتبارسنجی ETag/Last-Modified، در صورت فراهم‌بودن شرایط سرور
- توقف/ادامه، صف، مدیریت دانلودهای هم‌زمان، محدودیت سرعت، پروکسی، دسته‌بندی و جلوگیری از تکرار
- دانلود ویدیو از صفحات عمومی/مجاز YouTube و سایت‌های پشتیبانی‌شده `yt-dlp` و جریان‌های HLS/m3u8 فاقد DRM؛ همراه FFmpeg برای ادغام صوت و تصویر
- زیرساخت JavaScript با Deno و حل‌کننده EJS برای YouTube، **در نسخه ساخته‌شده توسط GitHub Actions** گنجانده می‌شود. سرویس‌های ویدیویی ممکن است محدودیت دسترسی، ورود به حساب یا تغییرات فنی داشته باشند.
- افزونه Chrome/Edge/Firefox با منوی راست‌کلیک، ارسال ویدیو و **دریافت خودکارِ اختیاری** دانلودهای جدید مرورگر با `downloads.onCreated`؛ انتقال دانلود فقط بعد از پذیرش برنامه انجام می‌شود
- اتصال رمزدار افزونه با یک کلید تصادفی؛ دسترسی سرویس فقط از `127.0.0.1`
- پوسته‌های «فیروزه‌ای»، «لاجورد و طلا»، «ترمه زرشکی»، «نگار ایرانی»؛ نقش هندسی الهام‌گرفته از کاشی ایرانی
- **بررسی خودکار** به‌روزرسانی هنگام شروع برنامه، دریافت نسخه جدید از GitHub Releases، بررسی هش SHA-256، و اجرای نصب‌کننده پس از **تأیید کاربر**
- میانبرهای Ctrl+N، Ctrl+V، انتخاب فایل/پوشه و Drag & Drop (در صورت پشتیبانی)

## سریع‌ترین راه دریافت فایل نصب EXE بدون نصب Python

**داخل این ZIP کد پروژه وجود دارد، نه نصب‌کننده آماده.** انتشار اتوماتیک با GitHub Actions روی ماشین Windows انجام می‌شود:

1. یک مخزن جدید GitHub مثلاً `MaherDownloadManager` ایجاد کنید و **محتویات پوشه پروژه** را مستقیماً در ریشه آن بارگذاری کنید، همراه پوشه مخفی `.github`. بهتر است از Git و `git push` استفاده کنید تا فایل‌های مخفی حذف نشوند.
2. در GitHub وارد **Actions → Windows installer and GitHub Releases → Run workflow** شوید. بعد از موفقیت، از صفحه همان اجرای Workflow، بخش **Artifacts → MaherDownloader-Windows-Installer** را دانلود و فایل ZIP خروجی را استخراج کنید.
3. برای انتشار رسمی در Releases می‌توانید از **Releases → Draft a new release → Choose a tag → Create new tag** تگ `v2.0.0` را ایجاد و انتشار دهید؛ جریان کاری اصلاح‌شده نصب‌کننده را به Release موجود اضافه می‌کند. روش جایگزین با Git:

   ```bash
   git tag v2.0.0
   git push origin v2.0.0
   ```

4. پس از پایان موفق workflow مربوط به تگ، در **Releases** فایل `MaherDownloader-Setup.exe` و `MaherDownloader-Setup.exe.sha256` قرار می‌گیرد. کاربر فقط EXE را باز می‌کند؛ Python، ffmpeg و Deno جداگانه لازم نیست.
5. برای انتشار نسخه بعدی شماره نسخه در `updater.py` (`APP_VERSION`)، اسکریپت `installer/MaherDownloader.iss` و پوسته افزونه‌ها را هم تغییر دهید؛ سپس tag جدید (مثلاً `v2.1.0`) ایجاد کنید. برنامه‌های نصب‌شده به‌طور خودکار وجود نسخه بالاتر را بررسی خواهند کرد.

> راهکار بروزرسانی **تأییدمحور** است: بدون رضایت کاربر هیچ EXE اجرا نمی‌شود. آپدیت فقط با فایل نصب‌کننده همنام و هش SHA-256 درست انجام می‌شود. برای انتشار عمومی بهتر است نصب‌کننده را امضای دیجیتال کنید.

## راه‌اندازی از سورس روی ویندوز

1. Python **3.12** را نصب کنید.
2. `START-WINDOWS.bat` را اجرا کنید. نخستین بار وابستگی‌ها از اینترنت نصب می‌شوند.
3. اگر می‌خواهید نصب‌کننده را روی رایانه خودتان بسازید، **Inno Setup 6** را نصب کنید، سپس `BUILD-EXE-WINDOWS.bat` را اجرا کنید. این روش برای پشتیبانی کامل YouTube به Deno نصب‌شده نیز نیاز دارد؛ نسخه GitHub Actions آن را بسته‌بندی می‌کند.
4. فایل قابل حمل در `dist/MaherDownloader/MaherDownloader.exe` و نصب‌کننده در `dist/installer/MaherDownloader-Setup.exe` تولید می‌شود (به شرط موفق‌بودن مراحل ساخت).

## نصب و اتصال افزونه

**Chrome**: `chrome://extensions` → Developer Mode → Load unpacked → پوشه `browser-extension`.

**Edge**: `edge://extensions` → Developer Mode → Load unpacked → پوشه `browser-extension`.

**Firefox، آزمایشی**: `about:debugging` → This Firefox → Load Temporary Add-on → فایل `browser-extension-firefox/manifest.json`. برای انتشار دائمی باید افزونه طبق سیاست‌های Firefox امضا شود.

در داخل برنامه روی **«کپی کد اتصال مرورگر»** کلیک کنید. پنجره افزونه را باز کنید، کد را وارد و **«ذخیره کد اتصال»** را انتخاب کنید. پس از مشاهده «برنامه متصل است»، در صورت تمایل تیک **«انتقال خودکار دانلودهای جدید مرورگر»** را روشن کنید.

این قابلیت طبق مجوز و محدودیت‌های Chrome/Firefox فقط دانلودهای قابل مشاهده از API مرورگر را پوشش می‌دهد. دانلودهایی با URLهای `blob:`, `data:`, سرویس‌های محافظت‌شده، و دریافت‌های اختصاصی درون پلیرها لزوماً قابل انتقال نیستند. اگر برنامه ویندوز پاسخ ندهد، مرورگر دانلود اصلی را ادامه می‌دهد.

## DRM و حقوق دسترسی

این برنامه **تشخیص و اعلام محدودیت DRM** را انجام می‌دهد؛ **حذف، دورزدن یا رمزگشایی DRM** پیاده‌سازی نشده است. HLS بدون DRM و HLS استانداردی که مالک آن مجاز به دریافتش هستید، در چارچوب قابلیت‌های `yt-dlp` قابل استفاده است. بعضی HLSهای محافظت‌شده حتی در صورت داشتن آدرس به فایل تبدیل نمی‌شوند. فهرست همه سایت‌ها و همه ویدیوها تضمین‌شده نیست.

## امنیت و عیب‌یابی

- برنامه یک کد اتصال تصادفی در `%LOCALAPPDATA%\MaherDownloader\downloads.json` ذخیره می‌کند؛ آن را عمومی نکنید.
- سرویس محلی فقط روی `127.0.0.1:17691` است و افزونه مجاز باید کد اتصال ارسال کند. صفحه وب عادی مجوز ندارد.
- نصب‌کننده به صورت **per-user** بدون نیاز به دسترسی Administrator طراحی شده است.
- رابط برنامه بعد از نصب نیاز به اتصال اینترنت برای اجرای خود نرم‌افزار ندارد؛ فقط دریافت فایل، متادیتای ویدیو و بررسی آپدیت به اینترنت نیاز دارند.
- در صورت عدم امکان ادامه، سرور ممکن است Range را پشتیبانی نکند؛ فایل از ابتدا دریافت می‌شود.
- به دلیل محدودیت دانلود پکیج در محیط تولید این بسته، آزمون زنده YouTube و ساخت EXE در اینجا انجام نشده‌اند. آزمون‌های داخلی موتور فایل، شبیه‌ساز رسانه، امنیت مرورگر و بروزرسانی اجرا شده‌اند؛ موفقیت ساخت Windows باید در GitHub Actions یا رایانه واقعی بررسی شود.
